# Agent Brain Resolver

Classify the task before reading more context.

| Task | Read first | Output |
|---|---|---|
| Debugging | `workflows/debug.md` | root cause, fix, verification |
| Shipping | `workflows/ship.md` | tests, diff summary, PR notes |
| Architecture | `architecture.md`, `decisions.md` | design note and migration plan |
| Risky area | `pitfalls.md` | guardrails and rollback plan |

Keep context narrow. Load only the files needed for the task.
